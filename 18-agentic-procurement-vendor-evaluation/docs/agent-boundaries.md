# Agent and Tool Boundaries

| Agent | Allowed responsibility | Explicitly forbidden |
|---|---|---|
| Sourcing | Build a bounded candidate set from approved catalog sources | Scrape arbitrary sites or contact vendors |
| Compliance | Check declared identity, required documents, conflicts, and fixture policy status | Claim real legal or sanctions clearance |
| Technical | Score declared technical criteria with evidence citations | Invent capabilities or alter criteria |
| Commercial | Calculate integer-money TCO from sealed bid components | Negotiate or move money |
| Risk | Record explainable security, continuity, delivery, and concentration risks | Suppress hard failures |
| Coordinator | Merge verified scorecards and draft a review packet | Award, purchase, issue a PO, or override a gate |

The plan is bounded to ten steps and twelve vendors. Tools are allowlisted and objectives are scanned as untrusted text. Parallel work is allowed only where outputs remain independently verifiable. Agent output is evidence, not authority.
