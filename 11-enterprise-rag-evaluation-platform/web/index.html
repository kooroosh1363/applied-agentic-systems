KNOW WHAT THE NUMBERS MEAN

            
Evidence, with boundaries.

            

              

                
01 / Retrieval quality

                

                  Recall, Precision@K, MRR and binary nDCG use authored
                  relevance labels. Duplicate ranks and unauthorized sources are
                  rejected. No-answer cases have N/A retrieval scores.
                

              

              

                
02 / Answer attribution

                

                  Exact quote support checks a complete sentence against
                  retrieved source text. Fact coverage uses corpus-owned
                  reference statements. Paraphrases remain unverified. A correct
                  quote can still come from a factually wrong source.
                

              

              

                
03 / Release policy

                

                  Metric gates, slice gates, expected safety outcomes and
                  compatible-baseline regression all contribute. A passing
                  result is eligible for human review, never an automatic
                  production release.
                

              

              

                
04 / Benchmark limits

                

                  33 synthetic, authored cases in English and Persian. They are
                  not independently human-reviewed. Thresholds are illustrative.
                  Phrase reranking is not a neural cross-encoder. Conflict
                  checks use authored topic/value metadata.
                

              

              

                
05 / Model adapters

                

                  Optional Ollama models run on your own computer. Configure
                  OLLAMA_EMBED_MODEL, OLLAMA_MODEL or OLLAMA_JUDGE_MODEL before
                  starting. Live model runs may be slow and are not guaranteed
                  to pass. No paid API is required.
                

              

              

                
06 / Statistical uncertainty

                

                  Paired bootstrap intervals describe observed outcome
                  differences on this synthetic set. Shared documents make cases
                  correlated. These intervals do not establish customer
                  performance or universal superiority.
