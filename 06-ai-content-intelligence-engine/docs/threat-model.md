# Threat model

Primary risks are forged webhooks, source poisoning, prompt injection, PII in support/sales text, SSRF through source URLs, copyright or platform-Terms violations, score gaming, unauthorized approval, analytics replay, tenant data leakage, secrets in workflow exports, and unbounded payloads. Implemented controls include shared-secret boundaries, HTTP(S)-only URL parsing without automatic fetching, bounded text and batches, source/evidence labels, injection/sensitive flags, deterministic policy, reviewer identity/role, idempotency, funnel invariants, audit, and secret scanning. Production still requires provider-grade signatures, allowlisted fetch proxy, malware/content scanning, PII redaction, SSO/RBAC, tenant isolation, encryption, retention/deletion, rate limiting, legal review, and security testing.
