# Agent boundaries

| Agent | Allowed responsibility | Forbidden |
|---|---|---|
| Strategy | Validate goal, evidence, and constraints | Change owner, policy, or budget |
| Audience | Build aggregate audience hypothesis | Identify or target individuals |
| Creative | Draft from approved facts | Invent claims or translations |
| Channel | Propose channel fit and timing | Publish or resolve credentials |
| Compliance | Check claims, disclosures, and brand rules | Grant legal clearance |
| Measurement | Define KPIs and planning allocation | Claim causality or authorize spend |
| Coordinator | Resolve bounded conflicts and assemble handoffs | Override policy, publish, or spend |

Consensus is not authority. If agents agree on an unsafe claim or a policy exception, the deterministic gate still blocks it. Contradictory proposals become review findings rather than being silently averaged.
