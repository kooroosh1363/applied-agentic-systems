# KPI and cost

The local path has zero API cost; infrastructure cost is not zero in a hosted deployment. Measure cost per resolved ticket as `(hosting + model + provider + human review cost) / resolved tickets`.

Recommended KPIs: first-response time, SLA breach rate, duplicate suppression, auto-resolution rate, approval rate, escalation precision, answer acceptance, reopened-ticket rate, delivery failure/DLQ rate, and human minutes saved. This repository supplies counters and fixtures, not real business results; all example figures are `simulated` until measured with consented operations.
