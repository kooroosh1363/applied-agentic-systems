# Contributing

1. Create a focused branch from `main`.
2. Keep each pull request limited to one project or shared-infrastructure change.
3. Run `npm run check` before pushing.
4. State which tests used mocks and which used real providers.
5. Update architecture, threat model, limitations, and evidence when behavior changes.
6. Never commit credentials or personal data.

See [Definition of Done](docs/standards/definition-of-done.md).
