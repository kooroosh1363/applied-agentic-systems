# Threat model

Assets include customer and line data, commercial prices, discounts, approval identity, acceptance evidence, invoices, payment events, and cash KPIs. Threats include forged requests, replay, price tampering, approval bypass, stale acceptance, invoice mutation, fake payment success, webhook duplication, overpayment abuse, PII leakage, and cross-tenant access. Current controls include shared-secret local ingress, idempotency, integer money, version binding, identified approval, immutable acceptance boundary, provider event uniqueness, verified evidence labels, exception routing, bounded retry, and audit. Production requires HMAC/mTLS, SSO/RBAC/MFA, tenant isolation/RLS, encryption, retention, immutable ledgers, fraud controls, PCI scope review, and security testing.
